# Механизм работы сортировки вставками: указатели i и j

## Ключевой момент: ДВА указателя

В сортировке вставками используются **два указателя**:

1. **`i`** — движется **только вперёд** (1, 2, 3, ..., n-1)
2. **`j`** — движется **назад** от `i-1` до `0`

---

## Как это работает на примере Шага 2

### Исходная ситуация (Шаг 2, i = 2):

```c
for (int i = 1; i < n; i++) {  // i = 2
    key = arr[i];              // key = arr[2] = 278
    j = i - 1;                 // j = 2 - 1 = 1
```

**Массив:**
```
[473] [576] [278] [852] [448] ...
  0     1     2     3     4
        ↑     ↑
        j    i,key
```

---

### Итерация 1 цикла while:

```c
while (j >= 0) {              // j = 1 >= 0 → ДА, входим
    comparisons++;
    if (arr[j] > key) {       // arr[1] = 576 > 278 → ДА
        arr[j + 1] = arr[j];  // arr[2] = arr[1] → сдвигаем 576 вправо
        swaps++;
        j--;                  // j = 1 - 1 = 0 ← ВОЗВРАЩАЕМСЯ НАЗАД
    }
}
```

**После сдвига:**
```
[473] [576] [576] [852] [448] ...
  0     1     2     3     4
  ↑           ↑
  j          i (key=278 сохранён отдельно)
```

**Важно:** 
- `i` остаётся = 2 (не меняется!)
- `j` стал = 0 (уменьшился на 1)
- `key = 278` сохранён в отдельной переменной

---

### Итерация 2 цикла while:

```c
while (j >= 0) {              // j = 0 >= 0 → ДА, продолжаем
    comparisons++;
    if (arr[j] > key) {       // arr[0] = 473 > 278 → ДА
        arr[j + 1] = arr[j];  // arr[1] = arr[0] → сдвигаем 473 вправо
        swaps++;
        j--;                  // j = 0 - 1 = -1 ← ИДЁМ ЕЩЁ НАЗАД
    }
}
```

**После сдвига:**
```
[473] [473] [576] [852] [448] ...
  0     1     2     3     4
  ↑           ↑
 j=-1        i (key=278)
```

**Важно:**
- `i` всё ещё = 2 (не изменился!)
- `j` стал = -1 (уменьшился ещё на 1)
- `key = 278` всё ещё сохранён

---

### Итерация 3 цикла while:

```c
while (j >= 0) {              // j = -1 >= 0 → НЕТ, выходим
    // этот код не выполняется
}
```

**Цикл завершён.**

---

### Вставка key:

```c
arr[j + 1] = key;             // arr[-1 + 1] = arr[0] = 278
```

**Финальный результат:**
```
[278] [473] [576] [852] [448] ...
  0     1     2     3     4
        ↑     ↑
       j+1   i
```

---

## Визуализация движения указателей

### Шаг 2 полностью:

```
Начало: i=2, j=1, key=278

[473] [576] [278] [852] [448] ...
  0     1     2     3     4
        ↑     ↑
        j    i,key

─────────────────────────────────

Итерация 1 while:
- Сравниваем: arr[j=1]=576 > key=278? ДА
- Сдвигаем: arr[2] = arr[1] = 576
- j-- → j=0

[473] [576] [576] [852] [448] ...
  0     1     2     3     4
  ↑           ↑
  j          i (key=278 в памяти)

─────────────────────────────────

Итерация 2 while:
- Сравниваем: arr[j=0]=473 > key=278? ДА
- Сдвигаем: arr[1] = arr[0] = 473
- j-- → j=-1

[473] [473] [576] [852] [448] ...
  0     1     2     3     4
  ↑           ↑
 j=-1        i (key=278 в памяти)

─────────────────────────────────

Выход из while (j=-1 < 0)

Вставка: arr[j+1] = arr[0] = key = 278

[278] [473] [576] [852] [448] ...
  0     1     2     3     4
  ↑     ↑
 j+1   i

─────────────────────────────────

Конец шага: i увеличивается до 3 (следующая итерация for)
```

---

## Схема работы указателей

```
i:  → → → → → → → → →  (всегда движется вперёд)
    1 2 3 4 5 6 7 8 9

j:  ← ← ← ← ← ← ← ← ←  (для каждого i идёт назад от i-1 до 0)
    (для i=2: j идёт 1→0→-1)
    (для i=4: j идёт 3→2→1→0→-1)
```

---

## Код с комментариями

```c
for (int i = 1; i < n; i++) {     // i движется ВПЕРЁД: 1, 2, 3, ...
    key = arr[i];                  // Сохраняем текущий элемент
    j = i - 1;                     // j начинается с позиции ПЕРЕД i
    
    // j движется НАЗАД: от i-1 до 0 (или до первого элемента <= key)
    while (j >= 0) {
        comparisons++;
        if (arr[j] > key) {
            arr[j + 1] = arr[j];   // Сдвигаем элемент вправо
            swaps++;
            j--;                   // j УМЕНЬШАЕТСЯ (идём назад)
        }
        else {
            break;                  // Нашли место, выходим
        }
    }
    
    arr[j + 1] = key;              // Вставляем key на правильное место
    // После этого i увеличивается на 1 (следующая итерация for)
}
```

---

## Ответ на вопрос

**НЕТ, указатель `i` НЕ возвращается назад.**

- **`i`** всегда движется только вперёд (1 → 2 → 3 → ...)
- **`j`** — это отдельная переменная, которая для каждого `i` идёт назад от `i-1` до `0`
- **`key`** сохраняется в отдельной переменной, поэтому мы можем сдвигать элементы, не теряя значение `arr[i]`

Когда мы "сравниваем с 576, потом с 473" — это происходит за счёт уменьшения `j` (j=1 → j=0), а не за счёт изменения `i`.
